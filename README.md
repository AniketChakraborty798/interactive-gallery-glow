The website focuses on a clean user interface, smooth interactions, modern animations, and an engaging visual experience.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm

You can also use Bun if preferred.

### 1. Clone the repository

```bash
git clone https://github.com/AniketChakraborty798/interactive-gallery-glow.git
```

### 2. Navigate to the project

```bash
cd interactive-gallery-glow
```

### 3. Install dependencies

Using npm:

```bash
npm install
```

Or using Bun:

```bash
bun install
```

### 4. Start the development server

Using npm:

```bash
npm run dev
```

Or using Bun:

```bash
bun run dev
```

The application will then be available at the local development address displayed in your terminal.

## 🧑‍💻 Development

This project uses **Vite** for a fast development experience and **React + TypeScript** for building reusable UI components.
